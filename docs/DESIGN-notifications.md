# ออกแบบ: การแจ้งเตือน

คำขอ: ตอนนี้ระบบไม่มีการแจ้งเตือนใดๆ เลย ทั้งที่มีเรื่องที่ต้องมีคนลงมือ เช่น ราคารออนุมัติ
ขายส่งรอจัดส่ง ใกล้ถึงกำหนดเก็บเงิน ขอตัดหนี้สูญ

ร้านเสนอ: ป๊อปอัพขึ้นทุกครั้งที่ล็อกอิน มีปุ่ม "ไม่แสดงข้อมูลนี้อีก" และถ้าข้ามวันแล้วรายการ
ยังค้าง ให้เตือนอีก

---

## สิ่งที่ต้องรู้ก่อน

- **กระดิ่งมุมขวาบนตอนนี้เป็นของตกแต่ง** กดแล้วไม่มีอะไร และจุดสีแดงบนกระดิ่ง
  เขียนตายไว้ในโค้ด (`components/layout/Header.tsx`) — ขึ้นตลอดเวลาไม่ว่าจะมีเรื่องหรือไม่
  คนจะเรียนรู้ว่าจุดแดงไม่มีความหมาย ซึ่งทำให้การแจ้งเตือนจริงที่จะทำต่อจากนี้ถูกมองข้าม
  ตั้งแต่วันแรก ต้องแก้เป็นอย่างแรก
- ข้อมูลที่ต้องใช้มีครบแล้วในระบบ — สถานะรออนุมัติ วันหน้าเช็ค กำหนดชำระ การยืนยันรับ
  ของคืน สิทธิ์ของแต่ละบทบาท — ไม่ต้องเก็บข้อมูลใหม่เพื่อจะรู้ว่าต้องเตือนอะไร
- แดชบอร์ดนับ "รอการอนุมัติ" (ส่วนลด/ปรับราคา, ขอตัดหนี้สูญ) และ "ประกันใกล้หมดอายุ"
  อยู่แล้ว การแจ้งเตือนต้องใช้สูตรเดียวกัน ตัวเลขสองที่จะได้ไม่ไม่ตรงกัน

---

## ความเห็นต่อข้อเสนอของร้าน

**ส่วนที่ดี และคงไว้:** เตือนแบบเห็นแน่ๆ ไม่ต้องไปหาเอง และถ้ายังไม่จัดการ พรุ่งนี้เตือนอีก

**สามจุดที่ปรับ:**

1. **"ทุกครั้งที่ล็อกอิน" → "เปิดแอปครั้งแรกของวัน"**
   ระบบจำการล็อกอินไว้หลายวัน บางคนแทบไม่ได้ล็อกอินใหม่เลย ป๊อปอัพจะแทบไม่ขึ้น
   ส่วนคนที่ล็อกอินบ่อย จะเจอหน้าต่างเดิมซ้ำจนกดปิดโดยไม่อ่าน ผูกกับ "วัน" แทน
   ได้ผลตรงกับที่ร้านต้องการ — วันละครั้งต่อคน

2. **"ไม่แสดงข้อมูลนี้อีก" → "รับทราบ · ซ่อนถึงพรุ่งนี้"**
   ถ้าซ่อนถาวรได้ เรื่องที่สำคัญที่สุดจะหายไปเงียบๆ ในวันที่รีบที่สุด ซึ่งขัดกับกติกา
   "ข้ามวันแล้วยังค้างให้เตือนอีก" ที่ร้านตั้งไว้เอง ซ่อนได้แค่ถึงพรุ่งนี้ก็ครบทั้งสองอย่าง

3. **เพิ่มกระดิ่งที่มีตัวเลขจริง** ป๊อปอัพเตือนวันละครั้ง แต่เรื่องที่เกิดกลางวัน (ขอราคา
   ตอนบ่ายสองโมง) ต้องมีที่ให้เห็น โดยไม่เด้งหน้าต่างขึ้นมาขัดงานซ้ำ

---

## ที่เสนอ: สามชั้น

### ชั้นที่ 1 · กระดิ่ง (ทุกหน้า ตลอดเวลา)

- ตัวเลขบนกระดิ่ง = จำนวนเรื่อง **ด่วน + ต้องทำ** ของคนนั้น ไม่มีเรื่อง = ไม่มีตัวเลข
- กดแล้วเห็นรายการแยกเป็น **ด่วน / ต้องทำ / แจ้งให้ทราบ**
- ทุกบรรทัดกดแล้วไปหน้ารายการที่กรองไว้แล้วตรงเรื่องนั้น (ใช้ลิงก์ชุดเดียวกับที่
  แดชบอร์ดใช้อยู่ เช่น กดขอตัดหนี้สูญ → เห็นเฉพาะ PO ที่ขอตัดหนี้สูญ)
- อัปเดตทุกครั้งที่เปลี่ยนหน้า และทุก 5 นาทีระหว่างเปิดค้างไว้

### ชั้นที่ 2 · หน้าต่างสรุปวันละครั้ง

- ขึ้นตอน **เปิดแอปครั้งแรกของวัน** ต่อคน — เฉพาะเมื่อมีเรื่อง **ด่วน หรือ ต้องทำ**
  ของคนนั้น ถ้าไม่มี ไม่ขึ้น
- ปุ่ม **รับทราบ · ซ่อนถึงพรุ่งนี้** — พรุ่งนี้ถ้ายังค้าง ขึ้นอีก
- ปุ่ม **ไปดู** ในแต่ละบรรทัด
- จำว่ารับทราบแล้ว **ในฐานข้อมูล** ไม่ใช่ในเครื่อง เปิดจากมือถือหลังกดรับทราบบน
  คอมพิวเตอร์แล้ว จะไม่เด้งซ้ำ

### ชั้นที่ 3 · เรื่องด่วนใหม่ระหว่างวัน

- ถ้ามีเรื่อง **ด่วน** ใหม่เกิดขึ้นหลังกดรับทราบไปแล้ว — ขึ้นแถบเล็กมุมจอ (ไม่ใช่
  หน้าต่างกลางจอ) บอกว่ามีเรื่องใหม่ พร้อมปุ่มไปดู หายเองเมื่อกดหรือเมื่อผ่านไปสักพัก
- เรื่อง **ต้องทำ** ใหม่ ไม่เด้ง แค่ตัวเลขบนกระดิ่งเพิ่ม

## เตือนเรื่องอะไร ใครเห็น

เห็นเฉพาะเรื่องที่ **ตัวเองจัดการได้** (ตามสิทธิ์) และ **เฉพาะสาขาของตัวเอง**
คนที่อนุมัติไม่ได้ ไม่ต้องเห็นว่ามีเรื่องรออนุมัติ — เห็นไปก็ทำอะไรไม่ได้ และทำให้
กระดิ่งมีเสียงดังจนไม่มีใครฟัง

## ทำงานอย่างไร (สำหรับการพัฒนา)

- **คำนวณจากข้อมูลจริงทุกครั้งที่ถาม ไม่มีตาราง "ข้อความแจ้งเตือน"** ที่ต้องคอยสร้างและลบ
  เรื่องที่อนุมัติไปแล้วจึงหายจากกระดิ่งทันที ไม่มีวันค้างหรือไม่ตรงกับความจริง
- **ใช้สูตรเดียวกับแดชบอร์ด** (`needsPriceApproval` และตัวอื่นๆ ใน `lib/domain`) กระดิ่งกับ
  การ์ดแดชบอร์ดจึงได้ตัวเลขเดียวกันเสมอ
- **นับที่ฐานข้อมูลในรอบเดียว** ผ่านฟังก์ชันที่คืนเฉพาะจำนวนและวันที่เก่าสุดของแต่ละเรื่อง
  (ไม่ดึงทั้งตารางมาทุก 5 นาที) และผ่าน RLS จึงเห็นเฉพาะสาขาของตัวเองโดยอัตโนมัติ
- **ตาราง `alert_acknowledgements` (ผู้ใช้, เรื่อง, วันที่)** เก็บการกดรับทราบ — หน้าต่างสรุป
  ขึ้นเมื่อ "วันนี้ยังไม่ได้รับทราบ" และมีเรื่องด่วน/ต้องทำ แยกต่อผู้ใช้ ข้ามเครื่องได้
- วันที่คิดตามปฏิทินร้าน (เวลาไทย) ไม่ใช่เวลาเซิร์ฟเวอร์ — "ข้ามวัน" จึงข้ามตอนเที่ยงคืน
  ที่ร้าน ไม่ใช่เจ็ดโมงเช้า

## ลำดับการทำ

1. **กระดิ่งตัวเลขจริง + รายการ** — แทนจุดแดงปลอม ครอบคลุมทุกเรื่องในตาราง
2. **หน้าต่างสรุปวันละครั้ง** + ตารางรับทราบ
3. **แถบเตือนเรื่องด่วนใหม่ระหว่างวัน**
4. (ถ้าต้องการ) หน้าตั้งค่าตัวเลขวัน และปิด/เปิดบางเรื่องต่อบทบาท

### นอกแอป (ยังไม่เสนอให้ทำตอนนี้)

ถ้าผู้บริหารไม่ได้เปิดแอปทุกวัน การแจ้งเตือนในแอปอย่างเดียวจะไม่พอ ทางที่ใช้กันคือ LINE
แต่ **LINE Notify ปิดบริการไปแล้ว** ต้องใช้ LINE Official Account ส่งผ่าน Messaging API
ซึ่งมีโควตาข้อความฟรีจำกัดต่อเดือนและต้องตั้งค่าบัญชีร้าน ควรตัดสินใจหลังใช้ชั้น 1–3
ไปสักระยะแล้วเห็นว่ายังพลาดเรื่องสำคัญ

## ที่ร้านตัดสินใจแล้ว

- **ผู้บริหาร/แอดมิน เห็นสองกลุ่มเสมอ** (15 ก.ย. 2569): เรื่องรออนุมัติทั้งหมด และรายการเรียกเก็บเงิน —
  ใกล้ถึงกำหนดชำระ เลยกำหนดชำระ และใบงานค้างชำระ ของทุกสาขาที่ตัวเองเข้าได้ ผูกกับสิทธิ์
  "ยืนยันเงินเข้า" ของขายส่ง ซึ่งค่าเริ่มต้นมีเฉพาะแอดมินและผู้บริหาร ถ้าร้านให้สิทธิ์นี้กับบทบาทอื่น
  บทบาทนั้นจะเห็นรายการเรียกเก็บเงินด้วย

## ต้องให้ร้านตัดสินใจ

1. **หน้าต่างสรุปขึ้นเมื่อไหร่** — เปิดแอปครั้งแรกของวัน (แนะนำ) หรือทุกครั้งที่ล็อกอิน
2. **ปุ่มซ่อน** — ซ่อนถึงพรุ่งนี้ (แนะนำ) หรือซ่อนถาวรต่อรายการ
3. **ตัวเลขวัน** — ราคารออนุมัติด่วนเมื่อค้างเกิน **1** วัน, PO รอจัดส่งเตือนเมื่อค้างเกิน
   **2** วัน, ใกล้ครบกำหนดชำระ/ค่าใช้จ่าย **3** วันก่อนถึง — ใช้ค่านี้ หรือปรับ
4. **เซลล์ (โหน่ง/เคน) มีบัญชีเข้าระบบไหม** — ถ้ามี ควรผูกบัญชีกับชื่อเซลล์ เพื่อให้เซลล์เห็น
   เฉพาะกำหนดชำระของลูกค้าตัวเอง ถ้าไม่มี ข้อนี้ข้ามได้
5. **ตารางเรื่องที่เตือน** — ขาดหรือเกินเรื่องไหน
