# Finnix Film — ระบบบริหารจัดการร้าน (Deploy Package)

วันที่แพ็ค: 2026-07-23

## สิ่งที่อยู่ในแพ็คนี้

- `finnix-film.html` — โค้ดทั้งหมดของระบบ ในไฟล์เดียว (React + Babel + Tailwind + Chart.js + SheetJS โหลดผ่าน CDN ไม่ต้อง build)

## เกี่ยวกับ "ฐานข้อมูล"

ระบบนี้ยังเป็น **prototype ที่ไม่มี backend/ฐานข้อมูลจริง** — ข้อมูลทั้งหมด (ใบงาน, สต็อก, ลูกค้า, ค่าใช้จ่าย, ผู้ใช้งาน ฯลฯ) เป็นข้อมูลตัวอย่างที่ฝังอยู่ในโค้ด (`const initialUsers`, `const initialRetailCustomers` และ seed อื่นๆ ในไฟล์ `finnix-film.html`) และเก็บอยู่ใน React state ในหน่วยความจำเบราว์เซอร์เท่านั้น

ผลคือ:
- ข้อมูลจะ **หายไปทุกครั้งที่รีเฟรชหน้าเว็บ** กลับไปเป็นค่าตัวอย่างเริ่มต้นเสมอ
- ไม่มีไฟล์ฐานข้อมูล (.db/.sql ฯลฯ) ให้แพ็ค เพราะไม่เคยมีการเชื่อมต่อฐานข้อมูลจริงในระบบนี้
- ถ้าจะใช้งานจริงกับข้อมูลที่บันทึกถาวรได้ ต้องเพิ่มระบบ backend + ฐานข้อมูลจริง (เช่น Supabase, Firebase, หรือ API ของคุณเอง) ซึ่งเป็นงานพัฒนาเพิ่มเติมที่ยังไม่ได้ทำ

## วิธี Deploy

เนื่องจากเป็นไฟล์ HTML เดี่ยวที่ไม่มีขั้นตอน build ใดๆ วิธี deploy ที่ง่ายที่สุดคือโฮสต์เป็นไฟล์ static:

1. **เปิดใช้งานทันทีบนเครื่อง**: ดับเบิลคลิก `finnix-film.html` เปิดด้วยเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพราะโหลดไลบรารีจาก CDN)
2. **โฮสต์บนเว็บ (แนะนำสำหรับใช้งานจริงกับทีม)**: อัปโหลดไฟล์นี้ไปยังบริการ static hosting เช่น Netlify, Vercel, GitHub Pages, Cloudflare Pages หรือ shared hosting ทั่วไป — ไม่ต้องตั้งค่า build command ใดๆ ตั้งไฟล์นี้เป็นหน้า index ได้เลย

## ข้อจำกัดที่ควรทราบก่อนใช้งานจริง

- ระบบ login เป็นการยืนยันตัวตนด้วยอีเมลเท่านั้น ยังไม่มีรหัสผ่าน/ระบบความปลอดภัยจริง
- ไม่มีการเชื่อมต่อฐานข้อมูล — ข้อมูลไม่ถูกบันทึกถาวร
- เหมาะสำหรับทดลองใช้/สาธิตฟีเจอร์ ยังไม่พร้อมสำหรับการใช้งานจริงกับข้อมูลลูกค้าจริงจนกว่าจะเพิ่ม backend
